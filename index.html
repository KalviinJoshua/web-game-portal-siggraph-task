About

Nebula Runner is a browser-based 3D endless runner built with Three.js, HTML5, CSS3 and JavaScript.

  • Procedural 3D graphics — ships, asteroids and crystals are generated in code.
  • Real-time rendering — a single WebGL loop driven by delta time.
  • Collision detection — lightweight bounding-sphere checks on active objects.
  • Responsive controls — keyboard on desktop, touch controls on mobile.
  • Performance optimization — object pooling, capped pixel ratio, reusable geometry.
